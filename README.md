## Deploy on Vercel

1. Upload this folder to a GitHub repository.
2. Keep the `assets` folder exactly as included. It contains the logo and banner images.
3. On Vercel, choose **Add New → Project** and import the GitHub repository.
4. Framework preset: **Other** (or leave the detected static option).
5. Build command: leave empty.
6. Output directory: leave empty / root.
7. Click **Deploy**.

If you already have the old SOLBRO project connected to this GitHub repository, push/commit these updated files and Vercel will redeploy automatically.

## Files

- `index.html` — website content and social links
- `styles.css` — responsive design
- `script.js` — small UI behavior
- `assets/solbro-logo.png` — mascot/logo
- `assets/solbro-banner.png` — banner artwork
