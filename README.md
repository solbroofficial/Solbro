# SOLBRO CALLS — Vercel Website

Premium responsive one-page landing page for SOLBRO CALLS.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive 3D/glass visual system
- `script.js` — smooth navigation
- `assets/solbro-logo.png` — mascot/logo
- `assets/solbro-banner.png` — banner artwork
- `vercel.json` — Vercel config

## Deploy with existing GitHub + Vercel
1. Replace the files in your existing GitHub repository with these files.
2. Keep the `assets` folder and both PNG files inside it.
3. Commit the changes.
4. Vercel will normally deploy automatically from GitHub.
5. If not, open Vercel → Deployments → latest → ⋯ → Redeploy.
